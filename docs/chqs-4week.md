### MySQL — root 超级用户

**来源:** 每日一练 App

**题目:** MySQL 中预设拥有最高权限的超级用户是？

**选项:**
1. Administrator
2. DBA
3. admin
4. root ✅

**我的答案:** root ✅
**正确答案:** root

**解析:**
- root 是 MySQL 内置的最高权限超级用户，拥有所有权限
- Administrator 是 Windows 系统管理员，非 MySQL 概念
- DBA 是数据库管理员职位，不是用户
- admin 是常见用户名，但不是 MySQL 预设超级用户
